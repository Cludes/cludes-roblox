# cludes-roblox

Roblox projects, one folder each.

| Project | What it is |
|---|---|
| [smart-house](smart-house) | A raised two-storey smart house with lights, a rolling garage door, an alarm system, hidden rooms, an underground cave garage and a physics elevator. Server-authoritative Luau, Rojo layout. |
| [garage-door](garage-door) | A standalone garage with a slow-closing door, status lamps and a safety stop, built by pasting one script into Studio's Command Bar. |

Each folder has its own README with setup steps.
